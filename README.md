### 🚗 [Портал инструкторов автошколы](https://github.com/GilachOne/instructor-portal)
**Коммерческий проект · PWA · интеграции · AI-проверка фото**

Внутренний портал для инструкторов и администраторов, заменивший прежний Telegram-бот. По описанию проекта, им пользуются более **100 сотрудников**.

- Отчёты об экзаменах, фотоотчёты о состоянии машин, бронирование автомобилей и заявки на ремонт.
- Проверка фотографий через **Yandex AI Studio**, повторная проверка по расписанию при сбоях.
- Хранение файлов в S3, интеграция с Google Sheets, вход с подтверждением звонком.
- PWA-интерфейс и административные справочники.

**Стек:** PHP 8.2, JavaScript, SQLite, REST API, S3, Yandex AI Studio, PWA.

### 🔗 [Реферальный портал автошколы](https://github.com/GilachOne/referral-portal)
**Коммерческий проект · внутренний сервис · CRM-интеграции**

Портал реферальной программы с личным кабинетом участника и административными функциями. Заменил прежний сценарий через чат-боты.

- Личные ссылки, статусы приглашённых, заявки на вознаграждения и push-уведомления.
- Синхронизация с **Битрикс24** через вебхуки и резервную периодическую проверку.
- Создание сделок и задач бухгалтеру, проверка участников через API учётной системы.
- Проверка подозрительных заявок, статистика каналов и журнал событий.

**Стек:** PHP 8.2, JavaScript, SQLite, PostgreSQL, Битрикс24 REST API, Web Push, nginx, cron.

### 💬 [Чат-боты автошколы: Telegram + MAX](https://github.com/GilachOne/drive-autoschool-bots)
**Практический кейс · LeadTeh · Битрикс24 · лидогенерация**

Сценарии привлечения и обработки заявок для сети автошкол, собранные в LeadTeh.

- Квалификация заявок: город, категория прав, запрос номера и передача менеджеру через CRM.
- Интеграции с **Битрикс24** через API и Albato, раздельная атрибуция источников рассылок.
- Автоматическое напоминание через 24 часа, если посетитель не оставил контакт.
- Публичные схемы и обезличенные JSON-экспорты, скриншоты диалога и конструктора.

**Стек:** LeadTeh, Telegram, MAX, Битрикс24 REST API, Albato.

### 🧟 [Drive or Die — квиз по ПДД](https://github.com/GilachOne/drive-or-die-quiz)
**Практический кейс · геймификация · Telegram Bot API**

Игровой тренажёр ПДД в формате зомби-квеста: **40 квестов**, интерактивные опросы, персонажи, рейтинг и внутренняя валюта.

- Универсальный движок вопросов в LeadTeh с вызовами **sendPoll / stopPoll** через Telegram Bot API.
- Подсчёт правильных ответов, ошибок, бонусов и результата первой попытки.
- Рейтинг и фиксация результатов через **Google Sheets**, визуализация в DataLens.
- Публичные схемы сценариев и обезличенные снимки интерфейса и логики.

**Стек:** LeadTeh, Telegram Bot API, Google Sheets, DataLens.
